# NDR Infotech – Website Review (ndrinfotech.com/index.html)

## Critical issues (fix first)
1. **Contradictory contact details** – shown phone +91 8722355999 but "Call Now" dials 8722355666; shown email hr@ndrinfotech.com but mailto goes to infotechndr@gmail.com. Leads are lost or misrouted. A Gmail address also weakens trust for an IT company.
2. **Typos in headline copy** – "Bussiness", "majorliy", "consultans", "Expertised", "Lets talk".
3. **No proof** – no clients, case studies, testimonials, certifications or team.
4. **Unexplained "Wealth Management" nav item** – confuses an IT-services positioning.
5. **No contact form / conversion path**; repeated generic CTAs ("Discover More").

## Positioning / content
- Value proposition is vague. Rewrite around outcomes: *Cloud, Data & BI, Migration, DevOps, Talent*.
- "Outsourcing" copy is unclear; define engagement models (Staff augmentation, Project, Managed team).
- "Over 2 decades" is a strong asset – use it prominently with concrete delivery examples.
- Tech stack not named – add a technologies section.
- Missing: process, FAQ, leadership, careers, blog/insights, social links (footer has an empty "#" link).

## SEO / technical
- Fix heading hierarchy (one H1, ordered H2/H3), add real alt text.
- Add unique title/meta description, Open Graph, canonical, JSON-LD Organization schema (done in the new build).
- Split services into dedicated pages for keyword depth (next phase).
- Add Privacy/Terms (exist) and a sitemap.xml / robots.txt.

## Design

- New design: dark premium theme, gradient accents, glass cards, scroll reveals, responsive nav, accessible contrast, reduced-motion support.
